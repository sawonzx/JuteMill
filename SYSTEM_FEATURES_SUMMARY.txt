2. ONE-COMMAND STARTUP
--------------------------------------------------------------------------------
Start all 3 backend API servers and all 3 frontend apps with a single command
from inside the client folder (or project root):

    cd client
    npm run dev

Automatically launches:
  * Backend Port 4000 (jute_mill_main)
  * Backend Port 4001 (jute_mill_fac_a)
  * Backend Port 4002 (jute_mill_fac_b)
  * Frontend Port 5173 (Main Office UI)
  * Frontend Port 5174 (Factory A UI)
  * Frontend Port 5175 (Factory B UI)

3. OPERATIONAL MODULES ACROSS DEDICATED PORTS
--------------------------------------------------------------------------------
Operational features present on every dedicated factory port (Ports 5174 & 5175):
  1. Sales Orders (/sales)
     - View orders, create orders, confirm, fulfill, and cancel orders.
  2. Invoices & Billing (/invoices)
     - Issue customer invoices, view balances, void/cancel invoices.
  3. Finance & Ledger (/finance)
     - Record incoming customer receipts, view accounts receivable.
  4. Inventory & Godowns (/inventory)
     - Warehouse balances, raw jute & finished goods stock movements,
       batch production, and transfer adjustments.
  5. Catalog & Customers (/products, /customers)
     - Product SKUs, standard price lists, customer directories.
  6. Operational Reports (/reports)
     - Branch sales reports, order fulfillments, and CSV exports.
  7. Branch User Management (/admin)
     - Create and edit local staff and accountant accounts.

Exclusive to Head Office Main Admin (Port 5173 only):
  * Mill Factories configuration tab (register/edit factory units).
  * Company Profile master settings.
  * System-wide consolidated audit logs.
  * Higher feature: "System Administration" (admin:manage).
  * Multi-branch consolidated dashboard and factory switcher filter.

5. PERMISSIONS & ACCESSIBILITY CONFIGURATION
--------------------------------------------------------------------------------
  * Add User Modal:
    - Assigned Mill Factory positioned cleanly above System Role.
    - System Role defaults to placeholder: "Select a role…".
    - "Accessibility & Permissions Configuration" appears only after selecting
      a role.
    - Modal dismissals: Top-right "✕" close button, backdrop click-outside,
      and Esc key.

  * Point-and-Click Granular Permissions:
    - Role defaults pre-populate automatically.
    - Admins can check/uncheck any specific permission to grant or revoke.
    - Visual indicators: "+ Custom Granted" (blue), "Role Default" (green),
      and "Revoked" (amber).
    - Quick action buttons: "Reset Defaults", "Grant All", "Clear".

  * Port Scope Enforcement in Permissions:
    - Main Admin sees all categories including "System Governance & Administration"
      (marked as "★ Head Office Exclusive").
    - Factory Admins only see features present on their dedicated port. Higher
      features like System Administration are completely excluded from their view.
    - "Grant All" for Factory Admin grants only the 16 port-level features.

  * Cross-Node Two-Way Synchronization:
    - When users are created, updated, or deleted on any branch, changes are
      saved in the branch database AND synchronized across to the Master
      Database (jute_mill_main), ensuring Head Office has a unified directory.
    - Password updates, permission changes, and status updates sync across nodes.
